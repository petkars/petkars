# Hi, I'm Shubham Petkar 👋

**Perception ML Engineer @ ERIC Robotics**

I work on real-time 3D LiDAR perception for autonomous inspection systems across railway, runway, and road environments.

Most of my work involves point clouds, registration, detection, sensor data pipelines, and making perception systems work reliably under real-world constraints.

## 🔭 What I Work On

- **Point-cloud registration** using FGR, FPFH, RANSAC and GICP, along with degeneracy detection and robustness analysis.
- **Change and FOD detection** using phase-correlation registration, Z-offset normalization and DBSCAN on profiler depth maps.
- **Railway track geometry** including versine measurement using multi-profiler data and geometric compensation.
- **Production sensor pipelines** using C++, multithreading, encoder-triggered acquisition, compression, ROS 2, Iceoryx and MCAP.
- **Perception performance** with a focus on latency, throughput, memory usage and reliable real-time processing.

## 🔬 Personal Research

### Occlusion-Robust 3D Perception

I'm working on a research project around camera-LiDAR fusion for 3D perception under severe occlusion.

The main question is:

> Can camera information and LiDAR geometry be combined to recover useful 3D information when an object is only partially visible?

The project is focused on:

- Camera-LiDAR fusion
- Severe occlusion
- 3D localization
- Sensor reliability
- Uncertainty estimation
- Controlled experiments
- C++ implementation
- CUDA/GPU optimization
- Real-time performance

Research is currently in the problem formulation and literature review stage.
